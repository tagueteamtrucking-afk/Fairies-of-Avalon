This directory stores all persistent memory files for the Fairies‑of‑Avalon project.

* **file-index.json** – generated index of files in the repository.
* **site-map.json** – generated map of entry pages, subpages, and assets.
* **owners.json** – canonical mapping of fairy/building owners and responsibilities.
* **fairy_function_matrix.json** – machine readable table of fairies and their functions.
* **prompts/** – plain‑text prompts describing what each room, building, or scene should look like.  These prompts can be fed into an image generator (e.g. Stable Diffusion, DALL‑E) to create bespoke artwork.

Place any new memory files you wish to persist across workflows here.  Do **not** scatter memory across the codebase; use this folder exclusively.
