# Avalon — Complete v4

- ROOT `index.html` (wallpaper hero, CTAs to Microapps and Run-All).
- Microapps: `pages/apps/` (Alexandria builder).
- Workflows: Run-All, optional LLM Bridge (OpenAI), optional Charlotte TTS (Azure).

## Install
Upload the pack to repo root, commit to **main**.

## Run
Actions → **Workflows — Sanity** → run.
Actions → **Avalon Run All** → run (defaults ok).

## Optional
Set secrets and run:
- `OPENAI_API_KEY` → **Overseers — LLM Bridge (Optional)**
- `AZURE_TTS_KEY`, `AZURE_TTS_REGION` → **Charlotte — TTS (Azure) (Optional)**
