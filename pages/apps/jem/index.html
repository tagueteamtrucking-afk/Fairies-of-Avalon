How to export Samsung Health data (optional)
  1. Open Samsung Health app → Menu → Settings → Download personal data (or Data → Download).
  2. Select at least Steps, Sleep, Heart rate; export as ZIP.
  3. Upload the ZIP(s) to your repo: /pages/apps/jem/imports/ (e.g., SamsungHealthExport_Ray.zip).
  4. Run Actions → Jem — Import Samsung Health (optional).
