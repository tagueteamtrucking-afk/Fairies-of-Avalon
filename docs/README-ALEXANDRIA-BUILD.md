# Alexandria Build — Offline-first

1) **Build world**: Actions → *Alexandria — Build World (All-in-One)*  
   - Title (optional), Prompt (optional)  
   - Events (default 7), NPCs (12), Regions (5)  
   - force_fallback = true (offline)

2) **Enrich**: run *Alexandria — Helpers Suite* (figures, continuity, scenes, bundle)

3) **Collaborate**: run *Tracy — Art Suite*, *Nina — 3D Suite*, *Charlotte — Pipelines Suite*

**No UI changes.** All artifacts land under `pages/apps/alexandria/worlds/**` (and `pages/apps/overseers/vrm-index.json`).
